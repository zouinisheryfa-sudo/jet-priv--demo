# Jet privé — démonstration immersive (concept ARMA Agency)

Expérience pilotée par le scroll : un film continu (`public/film`) avance, recule et s'arrête avec la molette.
Next.js · React · TypeScript · GSAP.

```bash
npm install
npm run dev   # http://localhost:5200
npm run build && npm start
```
